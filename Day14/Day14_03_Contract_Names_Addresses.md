# Day 14-03: Contract Names and Addresses

## Overview

Basic contract information - names and addresses - may seem simple, but errors here cause significant delays and complications. This topic covers best practices for accurately completing these fundamental contract sections.

---

## Names - Getting It Right

### The Basic Rule

> "Make sure the buyers and sellers names are correct... ask them for their ID or tell them to fill it in exactly as it is on their ID."

**Why ID Matching Matters:**
- Title searches based on legal name
- Deed must match exactly
- Mortgage documents require legal name
- Discrepancies cause delays

### Common Name Mistakes

**Example Problem:**
> "John Henry... great, his name is John Henry. Now we find out he's John Henry Louis the Third and we have to run all the searches again and we have to do all the addendums again because his ID doesn't reflect that."

**Types of Name Errors:**
| Error Type | Example | Impact |
|------------|---------|--------|
| Missing suffix | John Smith vs John Smith Jr. | Title search issues |
| Middle name | Mary Jane vs Mary J. | Document mismatch |
| Maiden name | Used maiden name, ID shows married | Addendum required |
| Spelling | Steven vs Stephen | Search problems |

### Best Practices for Names

1. **Request ID Copy:** Ask to see driver's license or passport
2. **Client Fills In:** Have them write their own name
3. **Verify Spelling:** Double-check unusual names
4. **Include All Parts:** Full legal name as on ID

### Tax Records Warning

> "Sometimes the tax records are not always complete or accurate."

**Don't Rely Solely On:**
- Tax records for spelling
- Previous deed for current name
- Client's verbal statement

**Always Verify Against:** Current government-issued ID

## Entities and Estates

### When Dealing with Non-Individuals

**Types of Fiduciaries:**
- LLC or Corporation
- Estate (deceased owner)
- Trust
- Power of Attorney

### Required Information

> "If you are dealing with an entity or an estate... make sure you have the name of the person who's authorized to sign on behalf of that entity or the estate."

**For Entities (LLC/Corp):**
- Entity's legal name
- Authorized signer's name
- Title/position of signer

**For Estates:**
- Estate name (Estate of [Deceased])
- Executor/Administrator name
- Whether probate is complete

**For Trusts:**
- Trust name
- Trustee name
- Date of trust

### If You Don't Have It

> "If you don't get it, I'll get it in attorney review, but in terms of completing the contract correctly, that's important to know."

**Attorney Will Need:**
- Copy of corporate resolution
- Letters testamentary (for estates)
- Trust document
- Power of attorney document

## Addresses - Property Identification

### The Obvious Importance

> "We have to know what property we're selling, but a lot of times where this is missed is when it's a condo."

**Address Components:**
- Street number and name
- Unit number (if applicable)
- City, State, ZIP

### Condo Unit Numbers

**Common Problem:**
> "I can't tell you how many times I get a contract and I don't have a unit number and we don't find out until later that a unit number is missing."

**Checklist for Condos:**
- [ ] Building address
- [ ] Unit number
- [ ] Floor (if relevant)
- [ ] Parking space number (if included)
- [ ] Storage unit number (if included)

### Properties with Two Addresses

**When This Happens:**
- Corner properties
- Properties spanning lot lines
- Historic addressing changes
- Municipal border situations

**How to Handle:**

> "Use what's on the tax record... and then queue the attorney into that - there are two - so that we can make that clear in attorney review."

**Steps:**
1. Use tax record address in contract
2. Note both addresses
3. Inform attorney of situation
4. Attorney will clarify in rider

### Properties in Two Towns

**Real Example:**
> "Some properties are also in two different towns... one street is in one town, one street is in the other."

**Complications:**
- OPRA searches needed in both towns
- Tax rates from both municipalities
- May have two separate tax bills
- School district determination

**Determining School District:**
> "The big decision was where did the kids go to school... it's where their bedrooms are."

---

## Two-Address Examples

### Example 1: Corner Property

**Situation:** House on corner of Main St and Oak Ave
- Tax record shows: 123 Main St
- Mail delivered to: 456 Oak Ave

**Solution:**
- Contract: 123 Main St (tax record)
- Note to attorney: "Also known as 456 Oak Ave"

### Example 2: Municipal Border

**Situation:** Property straddles Saddle River and Rockland County, NY
- Front of lot in New Jersey
- Back of lot in New York

**Complications:**
- Different state laws
- Different tax authorities
- School based on bedroom location

### Example 3: Town Name Variations

**Situation:** Hawthorne, Saddle River areas with addressing quirks
- Some towns have multiple address formats
- Historical vs current naming

**Solution:** Call town to verify:
- Mailing address
- Physical address
- Legal address for deed

## Why Accuracy Matters

### Downstream Effects of Errors

**Title Search Problems:**
- Wrong name = wrong records
- Missing liens or judgments
- Incomplete history

**Closing Delays:**
- Must correct documents
- Re-run searches
- Additional fees

**Post-Closing Issues:**
- Deed recording problems
- Title insurance complications
- Future sale difficulties

---

## Verification Checklist

### For Buyer Names
- [ ] Request copy of government ID
- [ ] Verify spelling of all names
- [ ] Include suffixes (Jr., III, etc.)
- [ ] Confirm marital status affects name
- [ ] Note any name changes pending

### For Seller Names
- [ ] Verify against deed
- [ ] Check tax records
- [ ] Confirm no name changes since purchase
- [ ] Identify all owners
- [ ] Note any deceased owners

### For Property Address
- [ ] Verify with tax records
- [ ] Include unit number if condo
- [ ] Note any alternate addresses
- [ ] Confirm municipality name
- [ ] Verify ZIP code

---

## Special Situations

### Recent Name Changes

**Marriage/Divorce:**
- May need both names
- "Jane Doe, formerly known as Jane Smith"
- Deed may need to reference both

### Death of Co-Owner

**If One Owner Deceased:**
- Surviving owner information
- Death certificate needed
- May need estate documentation

### Corporate Name Changes

**If Entity Renamed:**
- Current legal name
- "Formerly known as" reference
- State filing documentation

---

## Key Takeaways

1. **ID is Authority:** Names must match government ID exactly
2. **Tax Records Help but Verify:** May be outdated or incomplete
3. **Condos Need Unit Numbers:** Missing units cause problems
4. **Two Addresses = Tell Attorney:** Don't assume they'll find out
5. **Entities Need Authorized Signer:** Who can legally sign
